Ajuda

Encontre aqui informações úteis, guia de uso e canais de suporte.

Perguntas Frequentes

Como deve ser a nomeação dos arquivos?

Para utilizar as ferramentas de convenção de nomeação, os nomes dos arquivos das imagens devem possuir alguma das estruturas padronizadas, divididas por "-" ou "_".

Onde encontro o guia e a documentação completa?

O guia de uso pode ser baixado na seção abaixo. A documentação técnica completa está disponível no nosso repositório oficial no GitHub.

Como reporto um problema?

Para reportar bugs ou sugestões, você pode abrir uma "Issue" no GitHub ou enviar um e-mail diretamente para o suporte técnico listado no fim desta página.

Como faço para atualizar o aplicativo?

Acesse a seção de Atualizar no menu superior. O sistema verificará automaticamente se existe uma versão mais recente disponível para download.

O que é o modo de máxima performance?

Este modo habilita o processamento paralelo em múltiplos núcleos da CPU. Isso acelera consideravelmente as análises, mas consome mais recursos do computador. Não é recomendado para máquinas com hardware limitado.

Como faço para utilizar o aplicativo?

Acesse a Home, selecione o módulo desejado (Folhas ou Raízes), selecione a pasta com as imagens e escolha o pipeline de processamento. Os resultados serão gerados na mesma pasta de origem.
